## 一、什么是WIFI信道

Wi-Fi 信道 = Wi-Fi 在无线频谱里使用的一段频率位置；信道号告诉你“在哪”，信道宽度告诉你“占多宽”。(参考[chatgpt回答](https://chatgpt.com/s/t_6a72f9f472f481918ad17581a4a312fa))

**比如5Gwifi并非全部挤在一个频率上，而是要划分成不同的信道，每个信道对应一个中心频率 。** ^zhongxin


例如 5 GHz 的信道 149，中心频率大约是：
`5745 MHz`

**路由器和手机必须在同一个信道上才能通信。** 手机要和某个 Wi-Fi 路由器通信，它的 Wi-Fi 无线电必须调到这个路由器正在使用的那一组频率上。例如wifi工作在以下范围：
```
5 GHz
主信道：149
带宽：80 MHz
```

那么手机连上它以后，也会自动在这个 80 MHz 信道范围内收发数据。不是手机还待在信道 36，却能直接和信道 149 的路由器通信。

日常使用时不需要为手机主动选择信道，因为有如下过程：
```
手机扫描
 ↓
36：发现 Wi-Fi A
52：发现 Wi-Fi B
149：发现你家 Wi-Fi
 ↓
你点击你家 Wi-Fi
 ↓
手机把无线电调到 149 所在的信道
 ↓
开始和路由器通信
```
**有一个常见误区**，例如路由器显示:
```
Channel 149
80 MHz
```
并不是说一定在149信道上发射，而是可能在
```
149 + 153 + 157 + 161
```
几个信道一起组成的80MHz带宽上发射，因此严格意义是说，**149信道应该叫做主信道**

一般来说，**高频段更容易获得大带宽**，不是“频率越高物理上就自动能切更多信道”，而是现实频谱规划中，高频段往往能拿到更宽的连续频谱资源。可容纳的信道数量大致取决于：可用频谱宽度 ÷ 单信道带宽。
低频段传播好、覆盖远，因此历史上被广播、蜂窝、航空、卫星等大量系统瓜分；高频段更容易规划出几百 MHz 甚至 GHz 级连续带宽。这是“高频常见更宽信道”的主要现实原因。
## 二 、带宽(参考[chatgpt回答](https://chatgpt.com/s/t_6a730c12afd88191b290f20208f662a2))

**“带宽”这个词在计算机网络里其实有两个常见含义。**

① 无线电里的**频谱带宽**，单位 Hz/MHz  
② 网络里的**数据带宽**，单位 bit/s、Mbps、Gbps

这两种含义**相关，但并不是一回事**

假设一个wifi信号占用
```
5735 MHz ───────────────── 5755 MHz
```
那么它占用的带宽就是5755-5735=20MHz

中间位置5745就是[[WiFi篇#^zhongxin|中心频率]]

一般来说**频谱越宽，理论网速越高**，这可以用告诉公路对比，80MHz比20MHz宽四倍，相当于道路宽了四倍。

**香农公式**

$C=B\log_2(1+\mathrm{SNR})$
其中：
- C：理论最大数据率，bit/s
- B：频谱带宽，Hz
- SNR：信噪比

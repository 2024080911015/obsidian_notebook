## 一、什么是WIFI信道

Wi-Fi 信道 = Wi-Fi 在无线频谱里使用的一段频率位置；信道号告诉你“在哪”，信道宽度告诉你“占多宽”。(参考[chatgpt回答](https://chatgpt.com/s/t_6a72f9f472f481918ad17581a4a312fa))

**比如5Gwifi并非全部挤在一个频率上，而是要划分成不同的信道，每个信道对应一个中心频率 。** ^zhongxin


例如 5 GHz 的信道 149，中心频率大约是：
`5745 MHz`

**路由器和手机必须在同一个信道上才能通信。** 手机要和某个 Wi-Fi 路由器通信，它的 Wi-Fi 无线电必须调到这个路由器正在使用的那一组频率上。例如wifi工作在以下范围：
```
5 GHz
主信道：149
带宽：80 MHz
```

那么手机连上它以后，也会自动在这个 80 MHz 信道范围内收发数据。不是手机还待在信道 36，却能直接和信道 149 的路由器通信。

日常使用时不需要为手机主动选择信道，因为有如下过程：
```
手机扫描
 ↓
36：发现 Wi-Fi A
52：发现 Wi-Fi B
149：发现你家 Wi-Fi
 ↓
你点击你家 Wi-Fi
 ↓
手机把无线电调到 149 所在的信道
 ↓
开始和路由器通信
```
**有一个常见误区**，例如路由器显示:
```
Channel 149
80 MHz
```
并不是说一定在149信道上发射，而是可能在
```
149 + 153 + 157 + 161
```
几个信道一起组成的80MHz带宽上发射，因此严格意义是说，**149信道应该叫做主信道**

一般来说，**高频段更容易获得大带宽**，不是“频率越高物理上就自动能切更多信道”，而是现实频谱规划中，高频段往往能拿到更宽的连续频谱资源。可容纳的信道数量大致取决于：可用频谱宽度 ÷ 单信道带宽。
低频段传播好、覆盖远，因此历史上被广播、蜂窝、航空、卫星等大量系统瓜分；高频段更容易规划出几百 MHz 甚至 GHz 级连续带宽。这是“高频常见更宽信道”的主要现实原因。
## 二 、带宽(参考[chatgpt回答](https://chatgpt.com/s/t_6a730c12afd88191b290f20208f662a2))

**“带宽”这个词在计算机网络里其实有两个常见含义。**

① 无线电里的**频谱带宽**，单位 Hz/MHz  
② 网络里的**数据带宽**，单位 bit/s、Mbps、Gbps

这两种含义**相关，但并不是一回事**

假设一个wifi信号占用
```
5735 MHz ───────────────── 5755 MHz
```
那么它占用的带宽就是5755-5735=20MHz

中间位置5745就是[[WiFi篇#^zhongxin|中心频率]]

一般来说**频谱越宽，理论网速越高**，这可以用高速公路对比，80MHz比20MHz宽四倍，相当于道路宽了四倍。

**香农公式**

$C=B\log_2(1+\mathrm{SNR})$
其中：
- C：理论最大数据率，bit/s
- B：频谱带宽，Hz
- SNR：信噪比 ^5

## 三、各个WiFi协议([参考chatgpt回答](https://chatgpt.com/s/t_6a7337f3a24c8191b098e239f4d25334))
### 1.WiFi 5
Wi-Fi 5，也就是 **802.11ac**，主要工作在：
**5 GHz**
典型特征：

- 20 / 40 / 80 / 160 MHz 信道
- 最高 [[WiFi篇#^1|256-QAM]]
- 支持 [[WiFi篇#^6|MIMO]]
- 支持下行 [[WiFi篇#^7|MU-MIMO]]
- 理论最高约 6.9 Gbps（极端多空间流配置）
比如典型手机：
```
Wi-Fi 5
80 MHz
2×2 MIMO
256-QAM
```
[[WiFi篇#^2|最大PHY速率]]：
```
866.7 Mbps
```

### 2.WIFI 6
Wi-Fi 6 是：**802.11ax**
最大的提升不是峰值速度，而是在人，设备，AP多的环境中，让带宽利用更高效。
WIFI 6同时支持 2.4GHz和5GHz。
Wi-Fi 6 引入几个非常**重要的技术。**
###### 1.Wi-Fi 6 的 OFDMA（最核心技术）
WiFi5更像：
```
一条80 MHz高速公路

时刻1：
整条路 → 手机A

时刻2：
整条路 → 手机B

时刻3：
整条路 → 手机C
```
  
即使一台设备传输很少的数据，也可能占用一次传输机会
Wi-Fi 6 的 OFDMA 可以把一个信道进一步切成很多更小的：
**RU（Resource Unit，资源单元）**

例如：
```
80 MHz
┌────────┬──────┬──────────┬──────┐
│ 手机A  │手机B │ IoT设备C │手机D │
└────────┴──────┴──────────┴──────┘
```
这样多个用户可以使用不同的子载波传输数据
###### 2.Wi-Fi 6 把调制从 256-QAM 升到 1024-QAM
即采用[[WiFi篇#^3|1024-QAM]]的调制方式,因此，WiFi6的[[WiFi篇#^4|PHY速率]]为约 1201 Mbps。

###### 3.高阶QAM对[[WiFi篇#^5|SNR]]的要求更高
越高阶，每个符号携带的信息越多。因此稍微有点噪声，接收机就容易判断错误。所以离路由器很近，可能跑得很快。但是隔了几堵墙后，QAM自动降级，于是网速下降。

###### 4.Wi-Fi 6 的 BSS Coloring
相当于给不同 Wi-Fi 网络贴颜色，这样设备可以区分到不同的无线帧，如果信号又足够弱，有些情况下就可以更积极地复用频谱。因此WiFi 6在公寓楼里面比wifi 5 更有效
###### 5.WIFI 6的[[WiFi篇#^7|MU-MIMO]]更完善
Wi-Fi 5 已经有下行 MU-MIMO。WIFI6又加强了
```
下行 MU-MIMO
上行 MU-MIMO
```
所以数据传输可以更加并行

###### 6.Wi-Fi 6 的 TWT
主要是为了省电，例如让某个智能传感器不一直监听网络，而是隔10秒检测一次

# 安卓开发笔记

## 一、开发环境搭建

### Android Studio

Android 开发的标准 IDE 为 Android Studio，可从 [developer.android.com/studio](https://developer.android.com/studio) 下载。

### 基本环境要求

- **JDK**：Android Studio 自带 JDK，通常无需单独安装
- **Android SDK**：通过 SDK Manager 管理
- **Gradle**：构建工具，Android Studio 集成

### SDK Manager 常用配置

- SDK Platforms：下载目标 API level 的 SDK Platform
- SDK Tools：确认安装 Android SDK Build-Tools、Android Emulator、Android SDK Platform-Tools

## 二、项目结构

一个典型的 Android 项目结构：

```
app/
├── src/
│   ├── main/
│   │   ├── java/          # Java/Kotlin 源代码
│   │   ├── res/
│   │   │   ├── layout/    # 布局 XML 文件
│   │   │   ├── drawable/  # 图片资源
│   │   │   ├── mipmap/    # 应用图标（不同分辨率）
│   │   │   ├── values/    # 字符串、颜色、样式等
│   │   │   └── xml/       # 其他 XML 配置
│   │   └── AndroidManifest.xml
├── build.gradle           # 模块级构建配置
└── ...
├── build.gradle           # 项目级构建配置
└── settings.gradle
```

### AndroidManifest.xml 关键声明

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.example.myapp">

    <uses-permission android:name="android.permission.INTERNET" />

    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:theme="@style/Theme.MyApp">
        <activity
            android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

## 三、图标格式问题

^icon-format

### 自适应图标 (Adaptive Icons)

Android 8.0 (API 26) 开始引入自适应图标，由两层组成：

- **前景层 (Foreground)**：图标主体，透明背景
- **背景层 (Background)**：纯色或渐变背景

### 图标资源目录与格式

| 目录 | 用途 | 格式 |
|------|------|------|
| `mipmap-mdpi` | 中密度 (~160dpi) | PNG / WebP / XML |
| `mipmap-hdpi` | 高密度 (~240dpi) | PNG / WebP / XML |
| `mipmap-xhdpi` | 超高密度 (~320dpi) | PNG / WebP / XML |
| `mipmap-xxhdpi` | 超超高密度 (~480dpi) | PNG / WebP / XML |
| `mipmap-xxxhdpi` | 超超超高密度 (~640dpi) | PNG / WebP / XML |
| `mipmap-anydpi-v26` | 自适应图标 (API 26+) | XML（矢量） |

### 常见图标格式问题

**问题：图标在不同设备上显示不一致**

- **原因**：缺少对应密度的 mipmap 资源，或自适应图标配置不正确
- **解决**：为所有密度提供图标文件，或使用矢量图标（Vector Drawable）

**问题：图标在桌面显示为默认 Android 图标**

- **原因**：`ic_launcher.xml` 自适应图标文件格式错误，或 foreground/background 资源缺失
- **解决**：检查 `mipmap-anydpi-v26/ic_launcher.xml` 是否正确引用了两层资源

**问题：图标背景为白色方块**

- **原因**：PNG 格式图标没有包含正确的透明通道，或使用了没有透明度的 JPG 格式
- **解决**：使用带有透明通道的 PNG 格式

### 自适应图标 XML 示例

`res/mipmap-anydpi-v26/ic_launcher.xml`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```

### 使用 Image Asset Studio 生成图标

Android Studio 内置的 Image Asset Studio 可以一键生成所有密度的图标：

1. 右键 `res` → New → Image Asset
2. 选择图标类型（Launcher Icons / Adaptive and Legacy）
3. 提供前景图片和背景色/背景图
4. 自动生成所有密度和格式的图标文件

## 四、常见开发问题

### 编译错误排查

```bash
# 清理构建缓存
./gradlew clean

# 重新构建
./gradlew assembleDebug

# 查看依赖树（排查版本冲突）
./gradlew app:dependencies
```

### ADB 常用命令

```bash
# 查看连接的设备
adb devices

# 安装 APK
adb install app.apk

# 卸载应用
adb uninstall com.example.myapp

# 查看日志
adb logcat

# 发送广播
adb shell am broadcast -a <action>
```

## 五、构建与签名

### Debug 构建

Android Studio 默认使用 debug keystore 签名：

```
~/.android/debug.keystore
```

### Release 构建

需要生成或使用正式的签名密钥：

```bash
# 生成 keystore
keytool -genkey -v -keystore my-release-key.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias my-key-alias
```

在 `build.gradle` 中配置签名：

```gradle
android {
    signingConfigs {
        release {
            storeFile file("my-release-key.jks")
            storePassword "password"
            keyAlias "my-key-alias"
            keyPassword "password"
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
        }
    }
}
```

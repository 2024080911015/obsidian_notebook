# 浏览器扩展开发

## 一、概述

浏览器扩展（Browser Extension）是可以修改和增强浏览器功能的小程序。Chrome 扩展使用 Manifest V3 规范，Edge 和大部分 Chromium 内核浏览器兼容。通过扩展可以将自定义逻辑注入到浏览器内部，在目标网站的可信环境中运行。

> 相关阅读：[[浏览器开发者工具]] 用于调试扩展；[[爬虫与自动化/Playwright爬虫实战]] 可结合扩展实现高级爬取。

---

## 二、VS Code 插件开发入门

VS Code 插件和浏览器扩展的架构思想类似，都是通过清单文件（Manifest）声明能力，通过事件驱动的方式运行脚本。理解 VS Code 插件开发有助于更好地掌握浏览器扩展开发。

### 2.1 技术栈

- 主要使用 TypeScript（或 JavaScript）和 Node.js API
- 官方强烈推荐 TypeScript（代码提示和类型安全更好）

### 2.2 前置准备

需要安装：
- Visual Studio Code
- Node.js 和 npm
- Git

### 2.3 使用脚手架创建项目

```bash
npm install -g yo generator-code
yo code
```

根据提示选择：
- 类型：`New Extension (TypeScript)`
- 包管理器：`npm`

### 2.4 项目结构

```
HelloWorld/
├── package.json          # 插件清单文件（最核心）
├── src/
│   └── extension.ts      # 插件源代码入口
├── .vscode/              # 调试配置
└── tsconfig.json         # TypeScript 配置
```

**package.json 核心字段**：

```json
{
  "name": "helloworld",
  "main": "./out/extension.js",
  "activationEvents": ["onCommand:helloworld.helloWorld"],
  "contributes": {
    "commands": [{
      "command": "helloworld.helloWorld",
      "title": "Hello World"
    }]
  }
}
```

### 2.5 插件入口代码

```typescript
import * as vscode from 'vscode';

export function activate(context: vscode.ExtensionContext) {
    console.log('Congratulations, your extension is now active!');

    let disposable = vscode.commands.registerCommand('helloworld.helloWorld', () => {
        vscode.window.showInformationMessage('Hello World from HelloWorld!');
    });

    context.subscriptions.push(disposable);
}

export function deactivate() {}
```

### 2.6 运行和调试

在 VS Code 中按 `F5`，会启动"扩展开发宿主"窗口，这是一个加载了你的插件的干净 VS Code 环境。

在新窗口按 `Ctrl + Shift + P` -> 输入 `Hello World` -> 执行，即可看到右下角弹出提示信息。

### 2.7 核心概念

| 概念 | 说明 |
|------|------|
| **Activation Events** | 定义插件何时被激活（`onCommand`、`onLanguage`、`*` 等） |
| **Contribution Points** | 定义插件向 VS Code 添加了什么功能（commands、menus、keybindings 等） |
| **VS Code API** | `vscode.window`（UI 交互）、`vscode.workspace`（文件操作）、`vscode.editor`（编辑器操作） |

### 2.8 打包和发布

```bash
npm install -g vsce
vsce package    # 生成 .vsix 文件
```

## 三、浏览器扩展开发（Manifest V3）

### 3.1 整体架构

一个浏览器扩展由以下几个核心文件组成：

```
my_extension/
├── manifest.json          # 扩展的"身份证"（必须）
├── background.js          # 后台 Service Worker（扩展的大脑）
├── popup.html             # 点击图标弹出的面板
└── popup.js               # 弹出面板的交互逻辑
```

### 3.2 manifest.json（扩展清单文件）

```json
{
  "manifest_version": 3,
  "name": "TS Link Catcher",
  "version": "1.0",
  "description": "A simple extension to catch .ts video segment URLs.",
  "permissions": [
    "webRequest",
    "storage"
  ],
  "host_permissions": [
    "*://*.example.com/*"
  ],
  "background": {
    "service_worker": "background.js"
  },
  "action": {
    "default_popup": "popup.html"
  }
}
```

**关键字段说明**：

| 字段 | 说明 |
|------|------|
| `manifest_version` | 必须为 `3`（Manifest V3） |
| `permissions` | 扩展需要的权限（webRequest、storage 等） |
| `host_permissions` | 授权在哪些域名运行 |
| `background` | 后台 Service Worker 脚本 |
| `action` | 点击扩展图标时的行为 |

### 3.3 background.js（后台逻辑）

Service Worker 在后台持续运行（或按需唤醒），监听网络请求：

```javascript
// 存储捕获到的链接
let ts_links = [];

// 监听所有已完成的网络请求
chrome.webRequest.onCompleted.addListener(
  (details) => {
    // 检查 URL 是否以 .ts 结尾
    if (details.url.endsWith(".ts")) {
      if (!ts_links.includes(details.url)) {
        ts_links.push(details.url);
        console.log("Caught .ts link:", details.url);

        // 保存到浏览器的本地存储中
        chrome.storage.local.set({ captured_ts_links: ts_links });
      }
    }
  },
  {
    urls: ["<all_urls>"],       // 监听所有 URL
    types: ["media", "other"]   // 筛选请求类型
  }
);

// 监听来自 popup 的消息
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
    if (message.action === "clear_links") {
        ts_links = [];
        chrome.storage.local.set({ captured_ts_links: ts_links });
        sendResponse({status: "cleared"});
    }
});
```

**核心 API**：

| API | 用途 |
|-----|------|
| `chrome.webRequest.onCompleted` | 监听完成的网络请求 |
| `chrome.storage.local.set/get` | 本地存储 |
| `chrome.runtime.onMessage` | 接收来自其他组件的消息 |
| `chrome.runtime.sendMessage` | 发送消息到其他组件 |

### 3.4 popup.html（弹出面板）

```html
<!DOCTYPE html>
<html>
<head>
  <title>TS Catcher</title>
  <style>
    body { width: 200px; font-family: sans-serif; text-align: center; }
    button { margin-top: 10px; padding: 8px; cursor: pointer; }
  </style>
</head>
<body>
  <h3>TS Link Catcher</h3>
  <p>正在监听 .ts 链接...</p>
  <button id="clearButton">清空已捕获链接</button>
  <script src="popup.js"></script>
</body>
</html>
```

### 3.5 popup.js（面板逻辑）

```javascript
document.getElementById('clearButton').addEventListener('click', () => {
  chrome.runtime.sendMessage({ action: "clear_links" }, (response) => {
    if (response.status === "cleared") {
      window.close();
    }
  });
});
```

## 四、在 Playwright 中内置扩展

这是将扩展集成到爬虫中的终极方案：让 Playwright 启动的浏览器加载自定义扩展，然后通过 `page.evaluate` 与扩展通信。

### 4.1 核心思路

传统的爬虫是"从外部监听"网络请求。内置扩展方案相当于：

> **向浏览器内部派一个"卧底"，在可信环境中直接获取数据。**

### 4.2 完整 Python 脚本

```python
import os
import subprocess
import shutil
from playwright.sync_api import sync_playwright
from typing import List

# ==================== 配置 ====================
VIDEO_PAGE_URL = "https://www.example.com/videoplay/72979"
OUTPUT_DIR = "D:/videos"
OUTPUT_FILENAME = "final_video.mp4"
CAPTURE_DURATION_SECONDS = 90
EXTENSION_PATH = os.path.join(OUTPUT_DIR, "my_extension")

# ==================== 核心功能 ====================

def launch_browser_with_extension(url: str, duration: int, ext_path: str) -> List[str]:
    """使用持久化上下文启动带自定义扩展的浏览器，并获取数据。"""
    print("步骤 1: 启动带自定义扩展的浏览器...")

    # 为 Playwright 创建临时用户数据目录
    user_data_dir = os.path.join(OUTPUT_DIR, "playwright_temp_user_data")
    if os.path.exists(user_data_dir):
        shutil.rmtree(user_data_dir)

    # 使用 launch_persistent_context 加载扩展
    context = sync_playwright().start().chromium.launch_persistent_context(
        user_data_dir,
        headless=False,
        args=[
            f"--disable-extensions-except={ext_path}",
            f"--load-extension={ext_path}",
        ],
    )

    page = context.new_page()
    ts_links = []

    try:
        print(f"  正在打开页面: {url}")
        page.goto(url, timeout=90000)

        print(f"  页面加载完成。等待 {duration} 秒...")
        page.wait_for_timeout(duration * 1000)

        print("  正在从扩展的存储中读取捕获到的链接...")

        # 从扩展的 chrome.storage.local 中读取数据
        ts_links = page.evaluate("""
            () => new Promise(resolve => {
                chrome.storage.local.get('captured_ts_links', (result) => {
                    resolve(result.captured_ts_links || []);
                });
            })
        """)

    except Exception as e:
        print(f"出错: {e}")
    finally:
        print(f"捕获结束。扩展总共捕获到 {len(ts_links)} 个链接。")
        context.close()

    return ts_links


def create_local_m3u8(links: List[str], output_dir: str) -> str:
    """创建本地 M3U8 播放列表文件"""
    print("\n步骤 2: 创建本地 M3U8 文件...")
    if not os.path.exists(output_dir):
        os.makedirs(output_dir)

    local_m3u8_path = os.path.join(output_dir, "playlist.m3u8")
    with open(local_m3u8_path, 'w', encoding='utf-8') as f:
        f.write("#EXTM3U\n")
        f.write("#EXT-X-VERSION:3\n")
        f.write("#EXT-X-TARGETDURATION:15\n")
        for link in links:
            f.write("#EXTINF:5.0,\n")
            f.write(link + "\n")
        f.write("#EXT-X-ENDLIST\n")

    print(f"M3U8 文件已生成: {local_m3u8_path}")
    return local_m3u8_path


def download_with_ffmpeg(local_m3u8: str, output_path: str):
    """使用 FFmpeg 下载并合并视频"""
    print("\n步骤 3: 调用 FFmpeg 开始下载...")
    command = [
        'ffmpeg',
        '-protocol_whitelist', 'file,http,https,tcp,tls,crypto',
        '-i', local_m3u8,
        '-c', 'copy',
        '-bsf:a', 'aac_adtstoasc',
        '-y', output_path
    ]
    subprocess.run(command)
    print(f"视频下载完成: {output_path}")


def main():
    if not os.path.exists(EXTENSION_PATH):
        print(f"错误: 扩展路径不存在: {EXTENSION_PATH}")
        print("   请先创建 my_extension 文件夹及其四个文件。")
        return

    ts_links = launch_browser_with_extension(
        VIDEO_PAGE_URL, CAPTURE_DURATION_SECONDS, EXTENSION_PATH
    )

    if not ts_links:
        print("\n扩展未能捕获到任何链接，程序终止。")
        return

    final_output_path = os.path.join(OUTPUT_DIR, OUTPUT_FILENAME)
    local_m3u8_file = create_local_m3u8(ts_links, OUTPUT_DIR)
    download_with_ffmpeg(local_m3u8_file, final_output_path)


if __name__ == '__main__':
    main()
```

### 4.3 关键技术点

**1. 加载扩展的方式**：

```python
context = sync_playwright().start().chromium.launch_persistent_context(
    user_data_dir,
    headless=False,
    args=[
        f"--disable-extensions-except={ext_path}",
        f"--load-extension={ext_path}",
    ],
)
```

> **注意**：必须使用 `launch_persistent_context` 而非 `launch()`，否则扩展不会被加载。也必须在有头模式（`headless=False`）下运行。

**2. 与扩展通信**：

```python
# 从扩展的 chrome.storage.local 读取数据
ts_links = page.evaluate("""
    () => new Promise(resolve => {
        chrome.storage.local.get('captured_ts_links', (result) => {
            resolve(result.captured_ts_links || []);
        });
    })
""")
```

`page.evaluate` 在浏览器上下文中执行 JavaScript，可以访问扩展的 `chrome.storage` API。

### 4.4 运行步骤

1. 创建 `my_extension/` 文件夹，包含 manifest.json、background.js、popup.html、popup.js
2. 保存 Python 脚本为 `download_with_extension.py`
3. 运行：

```bash
python download_with_extension.py
```

4. 脚本会打开已加载扩展的浏览器，手动点击播放
5. 等待指定秒数后，自动从扩展读取链接并开始下载

## 五、扩展开发对比

| 维度 | VS Code 扩展 | 浏览器扩展（Chrome） |
|------|-------------|-------------------|
| 清单文件 | package.json | manifest.json |
| 入口文件 | extension.ts | background.js (Service Worker) |
| 运行环境 | Node.js | Browser Runtime |
| 语言 | TypeScript（推荐） | JavaScript |
| 激活方式 | activationEvents | permissions + host_permissions |
| 存储 | vscode 内置存储 | chrome.storage.local |
| 打包工具 | vsce（.vsix） | 直接加载/Chrome Web Store |

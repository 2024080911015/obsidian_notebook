# 宝塔面板部署

## 一、宝塔面板简介

宝塔面板（BT Panel）是一个服务器管理面板，提供可视化的 Web 界面来管理服务器。它极大简化了服务器运维工作，包括网站搭建、文件管理、数据库管理、计划任务等。

## 二、安装宝塔面板

### 准备工作

安装前需确认以下条件： ^pre-install-check

1. **纯净系统**：宝塔必须安装在未预装 Nginx/Apache/PHP/MySQL 的系统上。如果服务器曾安装过 Web 环境组件，建议重装系统后再装宝塔，否则会引起严重的软件冲突。
2. **系统版本**：支持 Ubuntu 16.04 至 22.04 的 64 位版本，推荐 Ubuntu 20.04 或 22.04 LTS。
3. **硬件要求**：内存建议 512MB 以上（推荐 768MB+），可用硬盘 300MB+。

### 安装步骤

#### 第一步：连接服务器

```bash
ssh root@你的服务器IP地址
```

如果是 `ubuntu` 用户，登录后切换到 root：

```bash
sudo su -
```

#### 第二步：执行安装脚本

Ubuntu 专用安装命令：

```bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh
```

系统会提示确认：

```
Do you want to install Bt-Panel to the /www directory now?(y/n):
```

输入 `y` 并回车。安装过程大约 2-10 分钟。

#### 第三步：记录登录信息

安装成功后，终端会显示关键登录信息（**务必立即保存**）：

- **外网面板地址**：`http://你的服务器IP:8888/随机安全码`
- **内网面板地址**：`http://你-的服务器内网IP:8888/随机安全码`
- **username**：面板登录用户名
- **password**：面板登录密码

#### 第四步：开放端口并登录

1. 登录云服务器提供商的管理后台
2. 在**安全组或防火墙**中开放 **8888 端口**
3. 浏览器访问外网面板地址
4. 使用保存的账号密码登录

首次登录后，宝塔会推荐安装 Web 环境套件（如 LNMP：Linux + Nginx + MySQL + PHP），可根据需求一键安装。

#### 第五步：常用管理命令

```bash
bt      # 显示管理菜单（16种功能）
bt 1    # 重启面板
bt 5    # 修改面板端口
bt 14   # 显示面板默认登录信息
```

^bt-install-commands

### 新版宝塔密码说明

新版宝塔面板的初始密码是**随机生成**的，不再使用默认密码。这个随机密码会在安装完成后的终端日志中显示。^bt-random-password

如果忘记了密码：
```bash
bt 14   # 在 SSH 终端中查看默认登录信息
```

## 三、Python 爬虫部署与 24 小时运行

### 第一阶段：本地准备工作

#### 1. 确保代码健壮

爬虫代码应有完整的异常处理（`try...except`），能应对网络失败、网站结构变化等问题，避免程序轻易崩溃。

#### 2. 生成依赖文件

在本地项目的虚拟环境中运行：

```bash
pip freeze > requirements.txt
```

#### 3. 项目打包

将 `main.py`、`requirements.txt`、配置文件等打包为 `.zip` 文件。

### 第二阶段：在宝塔中创建 Python 项目

#### 1. 安装 Python 项目管理器

宝塔面板 > 软件商店 > 搜索 "Python" > 安装"Python项目管理器"。

#### 2. 创建项目

1. 打开"Python项目管理器"，点击"添加项目"
2. 填写：
   - **项目名称**：如 `my_scraper`
   - **路径**：默认 `/www/wwwroot/项目名`
   - **Python 版本**：与本地开发一致
   - **框架**：选择 `virtualenv`
3. 点击"确定"，宝塔自动创建虚拟环境

### 第三阶段：上传代码与安装依赖

#### 上传文件

1. 宝塔面板 > "文件"
2. 导航到项目路径（如 `/www/wwwroot/my_scraper`）
3. 上传 `.zip` 文件，解压

#### 安装依赖

1. 回到"Python项目管理器"，找到项目，点击"设置"
2. 点击"终端"按钮进入虚拟环境
3. 执行：

```bash
pip install -r requirements.txt
```

#### 测试运行

```bash
python main.py
# 观察是否有报错
```

### 第四阶段：配置 24 小时运行

#### 方法 A：定时任务（Cron Job）-- 最常用，推荐 ^cron-method

适合"运行一次，抓取数据，然后结束"类型的爬虫。

1. 宝塔面板 > "计划任务" > 添加任务
2. 配置：
   - **任务类型**：Shell 脚本
   - **执行周期**：根据需求设置（如每小时第30分钟）
   - **脚本内容**：

```bash
# 1. 进入项目目录
cd /www/wwwroot/my_scraper

# 2. 激活虚拟环境
source /www/wwwroot/my_scraper/pyenv/bin/activate

# 3. 执行脚本，将日志输出到文件
python /www/wwwroot/my_scraper/main.py >> /www/wwwroot/my_scraper/scraper.log 2>&1
```

3. 保存后点击"执行"手动测试一次
4. 检查是否生成了 `scraper.log` 文件

> 脚本中的 `>> scraper.log 2>&1` 将所有输出（包括错误）追加到日志文件，便于排查问题。

#### 方法 B：进程守护 -- 适合持续运行的程序 ^daemon-method

适合包含 `while True` 循环或基于 Scrapy 的实时爬虫。

1. 打开"Python项目管理器"，进入项目"设置"
2. 在"启动文件/模块"中输入主脚本文件名（如 `main.py`）
3. 回到项目列表页，点击"启动"或"重启"
4. 宝塔的项目管理器（底层为 supervisor）会监控进程状态，崩溃后自动重启
5. 通过"日志"按钮查看实时输出

### 方法选择总结

| 场景 | 推荐方法 | 优点 |
|------|---------|------|
| 每隔 N 分钟/小时/天抓取一次 | 方法 A：计划任务 | 资源占用低，逻辑清晰，易于管理 |
| 程序需一直在线监控或实时处理 | 方法 B：进程守护 | 保证持续运行，崩溃自动恢复 |

## 四、日常管理

### 查看爬虫运行状态

- **定时任务**：宝塔面板 > 计划任务 > 查看执行日志
- **进程守护**：Python项目管理器 > 项目设置 > 查看日志

### 故障排查

1. 检查日志文件（`scraper.log`）中的错误信息
2. 确认服务器网络正常，目标网站可访问
3. 手动运行一次脚本测试：在虚拟环境终端执行 `python main.py`

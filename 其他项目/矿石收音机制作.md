# 矿石收音机制作

## 一、矿石收音机基本原理

矿石收音机由五个部分组成，无需任何电池或外部电源，完全依靠无线电波中的微弱能量驱动耳机发声。

### 五大组成部分

^components

| 部分 | 作用 |
|------|------|
| **天线 (Antenna)** | 在空中捕捉无线电广播信号。越长、越高，信号越强 |
| **地线 (Ground)** | 为零电位提供参考点，形成完整回路，增强信号强度和稳定性 |
| **调谐电路 (Tuning Circuit)** | 由电感线圈(L)和可变电容器(C)并联组成 LC 谐振电路，用于选台 |
| **检波器 (Detector)** | 将高频广播信号解调为音频信号。传统用方铅矿石，现代用锗二极管（1N34A/1N60） |
| **耳机 (Earphone)** | 将微弱音频电信号转换为声音。必须使用高阻抗耳机（>2000欧姆） |

### 电路原理

```
天线 → 调谐电路（L + C 并联） → 检波器（二极管） → 高阻抗耳机 → 地线
```

## 二、材料与工具清单

### 核心材料

| 零件 | 规格/型号 | 说明 |
|------|----------|------|
| 漆包铜线 | 0.2mm-0.5mm (约24-32 AWG) | 约需20-30米，制作电感线圈 |
| 线圈骨架 | 直径5-8cm，长10-15cm圆筒 | 卫生纸卷筒、PVC水管、硬纸板卷筒 |
| 可变电容器 | 270pF 或 365pF | 从旧收音机拆或网购，调台旋钮 |
| 锗二极管 | 1N34A 或 1N60 | 检波核心，不能用普通硅二极管(如1N4148) |
| 高阻抗耳机 | 陶瓷/晶体耳机，阻抗>2000欧姆 | 成功的关键！普通手机耳机不能用 |
| 底座 | 约15cm x 20cm | 木板、厚纸板、塑料板 |
| 接线柱/螺丝 | 5-6个 | 连接天线、地线、耳机 |
| 导线 | 若干 | 连接各元件 |

| 工具 | 用途 |

| 剪线钳/剥线钳 | 剪线和剥皮 |

## 三、制作步骤

### 第一步：制作电感线圈 (L)

^coil-making

1. 在圆筒骨架一端约 1cm 处钻两个小孔
2. 将漆包线一端穿过小孔，留出约 15cm 长的引线
3. 开始紧密、整齐地在圆筒上缠绕漆包线，**不要重叠**
4. 连续缠绕 80-100 圈左右（适用于中波 AM 广播）
5. 在绕完的末端也钻两个小孔，将线尾穿过并固定，同样留出 15cm 引线
6. **关键步骤：** 用小刀刮掉或用砂纸彻底打磨线圈两端引线的绝缘漆，直到露出闪亮的铜色。如果绝缘漆没去干净，电路就不通！

### 第二步：安装底座元件

1. 规划布局，将线圈、可变电容器、接线柱摆好位置
2. 用胶水或螺钉固定
3. 安装至少四个接线柱，分别标记为：`天线`、`地线`、`耳机1`、`耳机2`

### 第三步：连接电路（核心步骤）

^circuit-connection

**连接天线和地线到调谐电路：**

1. 将 `天线` 接线柱用导线连接到可变电容器的**定片接线端**（固定的那个引脚）
2. 同时从 `天线` 接线柱再引出一根线，连接到线圈的**顶端引线**
3. 将 `地线` 接线柱用导线连接到可变电容器的**动片接线端**（连接到旋转轴的那个引脚）
4. 同时从 `地线` 接线柱再引出一根线，连接到线圈的**底端引线**

至此，天线、地线、线圈、电容器已并联，组成 LC 调谐回路。

**连接检波器（二极管）：**

1. 将锗二极管 (1N34A) 的一端连接到线圈的**顶端**（连接天线的那一端）
2. 二极管有极性（通常有色环标记负极），但在这种简单电路中方向接反了通常也能工作
3. 二极管的另一端连接到 `耳机1` 接线柱

**连接耳机：**

1. 将高阻抗耳机的两个插头分别连接到 `耳机1` 和 `耳机2` 接线柱
2. 用一根导线将 `耳机2` 接线柱连接到 `地线` 接线柱

### 第四步：最终检查

- 仔细核对所有连线是否正确
- 检查所有连接点是否牢固，特别是漆包线头是否已刮掉绝缘漆
- 轻轻转动可变电容器旋钮，确保能顺畅转动

## 四、安装与使用

^usage

### 架设天线

找一根尽可能长的导线（**5-15米或更长**），一头接到 `天线` 接线柱上，另一头尽可能高、尽可能远地拉出去（伸出窗外、挂树上等）。

> **雷雨天绝对不能使用室外天线！**

### 连接地线

找一根导线接到 `地线` 接线柱，另一端连接到可靠的接地点：
- 金属自来水管（确保是金属的）
- 暖气片
- 直接插入湿润的土壤

**良好的接地是成功的关键。**

### 开始收听

1. 戴上高阻抗耳机
2. 在相对安静的环境里（最好是晚上，AM 信号传播更好）
3. **非常缓慢地旋转**可变电容器旋钮
4. 仔细聆听。当调谐电路的谐振频率与某个电台频率一致时，就能从耳机里听到广播声音

## 五、疑难解答

^troubleshooting

| 问题 | 排查方向 |
|------|----------|
| 完全没声音 | 1. 确认用的是高阻抗陶瓷/晶体耳机（不是普通耳机）<br>2. 检查所有连接点，漆包线头是否打磨干净<br>3. 确保地线连接可靠，换个接地点试试<br>4. 尝试更长的天线<br>5. 检查二极管是否损坏，或反过来接试试 |
| 声音非常小 | 优化天线（更长更高）和地线（更可靠接地点）。晚上信号会比白天强很多 |
| 多个电台混在一起 | 选择性不好，通常因为本地有强信号。尝试减少天线长度，或在线圈上抽头（比如在第30圈左右刮开一小段绝缘漆，把天线接到这里） |

## 六、普通收音机制作进阶方案

如果矿石收音机成功，可以进阶制作需要电池供电的"普通收音机"。

### 方案一：单管再生式 AM 收音机

^single-tube-radio

**特点：** 只用一个晶体管，通过"再生"（正反馈）实现高放大倍数。

| 项目 | 详情 |
|------|------|
| 难度 | 中等（需要焊接） |
| 核心元件 | NPN 高频晶体管（如 9018, 2SC9018, S9018） |
| 电源 | 1.5V-3V（一至两节 AA 电池） |
| 输出 | 高阻抗耳机，或加 LM386 功放驱动喇叭 |

**关键元件：**
- 晶体管：NPN 高频小功率（9018 系列）
- 电感线圈：主线圈 80 圈 + 再生线圈 15-20 圈（两个线圈绕向一致）
- 可变电容器：270pF 或 365pF
- 阻容元件：100kΩ、1kΩ 电阻，0.01μF、100μF 电容

**制作要点：**
- **线圈是关键：** 再生线圈反馈强度决定灵敏度。如果啸叫说明反馈太强，减少圈数或改变接头。如果声音小说明反馈太弱
- **晶体管引脚：** 确认基极(b)、集电极(c)、发射极(e)，不能接错
- **调试：** 接天线地线和电源后，一边旋转可变电容选台，一边调整反馈强度，直到声音最响亮清晰且不啸叫

### 方案二：IC 调频收音机套件

^ic-fm-radio

| 项目 | 详情 |
|------|------|
| 难度 | 低（元件多但原理简单，照图焊接即可） |
| 核心IC | CD9088 (FM接收) + TDA2822 (音频功放) |
| 电源 | 3V（两节 AA 电池） |
| 输出 | 小喇叭或普通耳机 |

**强烈建议购买 DIY 套件**（搜索"FM收音机DIY套件"或"9088收音机套件"），理由：
- 元件齐全（电阻、电容、IC、PCB板、外壳都有）
- 印刷电路板降低制作难度
- 经过验证的成熟方案，焊接无误基本都能成功

**焊接顺序：** 从低到高、从简到繁。先焊电阻、二极管，再焊电容、IC 插座，最后焊可变电容、耳机座等大元件。

### 方案三：Arduino 数字调频收音机

^arduino-radio

| 项目 | 详情 |
|------|------|
| 难度 | 较高（需要 Arduino 编程基础和模块连接知识） |
| 核心元件 | Arduino UNO/Nano + TEA5767 FM模块 + LCD1602/OLED显示屏 |
| 电源 | 5V（USB 供电） |
| 输出 | 外接有源音箱或 LM386 功放 + 喇叭 |

**连接方式：** TEA5767 模块和 I2C 屏幕都通过 I2C 总线（SDA、SCL 引脚）与 Arduino 通信。

**软件实现：**
1. 初始化 LCD 屏幕和 TEA5767 模块
2. 读取按钮或旋转编码器的状态
3. 根据用户操作通过 I2C 指令设置接收频率
4. 从 TEA5767 读取当前频率，显示在屏幕上

### 方案对比

| 方案 | 优点 | 缺点 | 适合人群 |
|------|------|------|----------|
| 矿石收音机 | 无需电源，深入理解无线电原理 | 声音小，只能AM，需要天线地线 | 初学者，无线电爱好者 |
| 单管AM收音机 | 深入理解放大原理，成本极低 | 性能较弱，需要调试技巧 | 电子爱好者 |
| IC调频收音机套件 | 性能好，收FM，成功率高 | 像"拼图"，原理理解不深 | 新手，想快速获得实用收音机 |
| Arduino数字收音机 | 功能强大（数字调谐、屏幕），可扩展 | 成本较高，需要编程 | 创客、编程爱好者 |

# 股票特征提取与策略回测

> 基于 MATLAB 的股票特征提取与策略回测框架研究

## 一、研究任务概述

^overview

本项目针对股票日线交易数据，系统性地开展量化交易策略研究，包含三大核心任务：

1. **特征工程**：基于日线数据计算技术指标（换手率、MACD、RSI、KDJ）
2. **交易策略设计**：设计基于多指标组合的"复合特征"买入信号
3. **策略回测与评估**：历史数据模拟交易，计算平均收益率、最大收益率、最大亏损率等关键绩效指标

## 二、数据准备

### 数据结构

实验数据以 `\day` 子文件夹存放，每个 CSV 文件对应一支股票的日线数据（自 2024.1.1 起）。

关键字段：`day`（日期）、`code`（股票代码）、`open`、`close`、`high`、`low`、`volume`、`amount`、`zf`（振幅）、`zdf`（涨跌幅）、`zde`（涨跌额）、`hsl`（换手率）。

### MATLAB 数据加载模块

^data-loading

```matlab
function stock_data = load_stock_data(data_directory)
% load_stock_data - 从指定目录加载所有股票的日线数据
    if ~isfolder(data_directory)
        error('指定的目录不存在: %s', data_directory);
    end

    file_list = dir(fullfile(data_directory, '*.csv'));
    if isempty(file_list)
        warning('在目录 %s 中未找到任何CSV文件.', data_directory);
        stock_data = {};
        return;
    end

    num_files = length(file_list);
    stock_data = cell(1, num_files);

    fprintf('开始加载 %d 支股票数据...\n', num_files);

    for i = 1:num_files
        file_path = fullfile(data_directory, file_list(i).name);
        try
            opts = detectImportOptions(file_path);
            opts = setvartype(opts, 'day', 'datetime');
            opts.VariableNamingRule = 'preserve';

            raw_table = readtable(file_path, opts);
            stock_timetable = table2timetable(raw_table, 'RowTimes', 'day');
            stock_data{i} = stock_timetable;
            fprintf('已成功加载: %s\n', file_list(i).name);
        catch ME
            warning('加载文件 %s 时发生错误: %s. 已跳过此文件.', file_list(i).name, ME.message);
            stock_data{i} = [];
        end
    end

    stock_data = stock_data(~cellfun('isempty', stock_data));
    fprintf('数据加载完成. 成功加载 %d 支股票.\n', length(stock_data));
end
```

> 使用 `readtable` + `table2timetable` 是现代推荐做法，`timetable` 是金融工具箱原生的时序数据格式，`csvread` 已被不推荐使用。

## 三、技术指标计算

### 参数总览

| 指标 | 参数 | 标准值 |
|------|------|--------|
| MACD | Fast EMA / Slow EMA / Signal EMA | 12 / 26 / 9 |
| RSI | Lookback Period | 14 |
| KDJ | N Period / K Smoothing / D Smoothing | 9 / 3 / 3 |
| 换手率 | N/A | 文件中直接提供 `hsl` 字段 |

### 换手率

直接使用数据中的 `hsl` 字段（每日换手率百分比）：

```matlab
turnover_rate = stock_tt.hsl;
```

**市场含义：**
- 价涨量增：上涨趋势健康
- 价涨量缩：上涨动力不足
- 高位放量：可能是出货信号
- 低位放量：可能是新资金入场

### MACD

^macd

**公式：**
- `DIF = EMA(Close, 12) - EMA(Close, 26)`
- `DEA = EMA(DIF, 9)`
- `MACD柱 = DIF - DEA`

```matlab
function [macd_line, signal_line, macd_hist] = calculate_macd(stock_tt)
    required_vars = {'High', 'Low', 'Open', 'Close'};
    if ~all(ismember(required_vars, stock_tt.Properties.VariableNames))
        error('输入timetable必须包含 High, Low, Open, Close 列');
    end

    [MACDvec, nineperma] = macd(stock_tt);
    macd_line = MACDvec.Close;
    signal_line = nineperma.Close;
    macd_hist = macd_line - signal_line;
end
```

**信号解读：**
- **金叉：** DIF 从下向上穿 DEA -- 看涨买入
- **死叉：** DIF 从上向下穿 DEA -- 看跌卖出
- **零轴穿越：** DIF 穿越零轴向上 -- 多头市场
- **背离：** 股价新高但 MACD 未新高 -- 趋势反转预警

### RSI

^rsi

**公式：**
- `RS = N周期内平均上涨幅度 / N周期内平均下跌幅度`
- `RSI = 100 - 100/(1 + RS)`

```matlab
function rsi_values = calculate_rsi(stock_tt, period)
    if nargin < 2
        period = 14;
    end
    close_prices = stock_tt.Close;
    rsi_values = rsindex(close_prices, period);
end
```

**信号解读：**
- RSI > 70：超买，潜在卖出信号
- RSI < 30：超卖，潜在买入信号
- 强牛市中 RSI 在 40-90 区间，40-50 为支撑位
- 熊市中 RSI 在 10-60 区间，50-60 为阻力位

### KDJ

^kdj

**公式（自实现，无内置函数）：**
- `RSV = (C - Ln) / (Hn - Ln) * 100`
- `K = 2/3 * K(t-1) + 1/3 * RSV`
- `D = 2/3 * D(t-1) + 1/3 * K`
- `J = 3*K - 2*D`

```matlab
function [K, D, J] = calculate_kdj(stock_tt, n, a, b)
    if nargin < 2, n = 9; end
    if nargin < 3, a = 3; end
    if nargin < 4, b = 3; end

    high_prices = stock_tt.High;
    low_prices = stock_tt.Low;
    close_prices = stock_tt.Close;
    data_len = length(close_prices);

    highest_high = movmax(high_prices, [n-1 0]);
    lowest_low = movmin(low_prices, [n-1 0]);

    rsv = 100 * (close_prices - lowest_low) ./ (highest_high - lowest_low);
    rsv(isnan(rsv)) = 50;

    K = zeros(data_len, 1);
    D = zeros(data_len, 1);
    K(1) = 50;
    D(1) = 50;

    weight_k = 1/a;
    weight_d = 1/b;

    for i = 2:data_len
        K(i) = (1 - weight_k) * K(i-1) + weight_k * rsv(i);
        D(i) = (1 - weight_d) * D(i-1) + weight_d * K(i);
    end

    J = 3 * K - 2 * D;
end
```

**信号解读：**
- **金叉：** K 线上穿 D 线（尤其在 20 以下更强）
- **死叉：** K 线下穿 D 线（尤其在 80 以上更强）
- D > 80 超买，D < 20 超卖
- J > 90 短期顶部，J < 10 短期底部

## 四、复合信号策略设计

### 设计理念

^composite-signal

依赖单一指标是脆弱的。复合信号的核心思想是：一个高质量的交易信号应得到**多个不同维度、不同时间尺度的指标共同确认**。

**决策哲学：**
- **触发器 (Trigger)**：用最敏感的指标捕捉潜在交易时机
- **过滤器 (Filter)**：用较不敏感的指标验证时机与市场大方向一致

### 买入策略（复合信号）

买入信号在当日收盘后当且仅当以下**三个条件全部满足**时触发：

1. **KDJ 金叉触发：** `K(t) > D(t)` 且 `K(t-1) <= D(t-1)`
2. **RSI 状态过滤：** `RSI(t) < 70` 且 `RSI(t) > RSI(t-1)`
3. **MACD 趋势过滤：** `DIF(t) > DEA(t)`

交易执行：在第 `t+1` 天开盘价买入。

### 卖出策略

采用简化的固定持有期策略：**买入后第 2 个交易日卖出**（t+3 天开盘价卖出）。

> 这是教学简化。完整的实用系统会设计基于技术指标的动态卖出策略（KDJ 死叉、RSI 超买区、移动止损止盈等）。

### 信号生成函数

```matlab
function buy_signal = generate_composite_signal(indicator_tt)
    K = indicator_tt.K;
    D = indicator_tt.D;
    RSI = indicator_tt.RSI;
    DIF = indicator_tt.DIF;
    DEA = indicator_tt.DEA;

    data_len = length(K);
    buy_signal = false(data_len, 1);

    for i = 2:data_len
        % 条件1: KDJ金叉
        kdj_cross = (K(i) > D(i)) && (K(i-1) <= D(i-1));

        % 条件2: RSI状态过滤
        rsi_filter = (RSI(i) < 70) && (RSI(i) > RSI(i-1));

        % 条件3: MACD趋势过滤
        macd_filter = (DIF(i) > DEA(i));

        % 复合信号: 所有条件必须同时满足
        if kdj_cross && rsi_filter && macd_filter
            buy_signal(i) = true;
        end
    end
end
```

## 五、回测引擎设计

### 回测算法

^backtest

逐日循环的事件驱动型回测框架：

```matlab
% --- 主回测脚本: run_backtest.m ---
clear; clc; close all;

% 1. 设置与数据加载
data_folder = 'day';
all_stocks = load_stock_data(data_folder);

% 2. 初始化结果存储
num_stocks = length(all_stocks);
results = table('Size', [num_stocks, 5],...
                'VariableTypes', {'string', 'double', 'double', 'double', 'double'},...
                'VariableNames', {'StockCode', 'NumTrades', 'AvgReturn', 'MaxReturn', 'MaxLoss'});

% 3. 遍历每支股票进行回测
for k = 1:num_stocks
    fprintf('正在回测第 %d / %d 支股票...\n', k, num_stocks);

    stock_tt = all_stocks{k};
    stock_code = stock_tt.code(1);
    results.StockCode(k) = stock_code;

    if height(stock_tt) < 50
        fprintf('股票 %s 数据太少, 已跳过.\n', stock_code);
        continue;
    end

    [K, D, J] = calculate_kdj(stock_tt);
    [DIF, DEA, ~] = calculate_macd(stock_tt);
    RSI = calculate_rsi(stock_tt);

    indicator_table = table(K, D, J, DIF, DEA, RSI, 'RowNames', string(stock_tt.Time));
    indicator_tt = table2timetable(indicator_table);

    buy_signal = generate_composite_signal(indicator_tt);

    trade_log = [];
    is_in_market = false;

    for t = 30:(height(stock_tt) - 3)
        % 检查卖出
        if is_in_market && (t == exit_day_index)
            sell_price = stock_tt.open(t);
            trade_return = (sell_price - buy_price) / buy_price;
            trade_log = [trade_log; trade_return];
            is_in_market = false;
        end

        % 检查买入
        if ~is_in_market && buy_signal(t)
            buy_price = stock_tt.open(t+1);
            is_in_market = true;
            exit_day_index = t + 3;
        end
    end

    if ~isempty(trade_log)
        results.NumTrades(k) = length(trade_log);
        results.AvgReturn(k) = mean(trade_log);
        results.MaxReturn(k) = max(trade_log);
        results.MaxLoss(k) = min(trade_log);
    else
        results.NumTrades(k) = 0;
        results.AvgReturn(k) = NaN;
        results.MaxReturn(k) = NaN;
        results.MaxLoss(k) = NaN;
    end
end

% 4. 显示结果
fprintf('\n--- 回测结果汇总 ---\n');
results = rmmissing(results);
disp(results);

overall_avg_return = mean(results.AvgReturn, 'omitnan');
total_trades = sum(results.NumTrades);
fprintf('\n总体平均单次交易收益率: %.2f%%\n', overall_avg_return * 100);
fprintf('总交易次数: %d\n', total_trades);
```

### 关键绩效指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 平均收益率 | `mean(returns)` | 每次出手的平均盈利水平 |
| 最大收益率 | `max(returns)` | 单笔最高盈利 |
| 最大亏损率 | `min(returns)` | 单笔最大亏损（风险暴露） |

### backtestEngine（MATLAB 专业回测框架）

MATLAB 金融工具箱提供 `backtestEngine` 框架，优势：
- 稳健性与标准化（处理日期对齐、前瞻性偏误）
- 原生支持交易成本、滑点、融资融券等
- `summary` 和 `equityCurve` 一键生成专业报告

## 六、回测局限性

^limitations

| 假设 | 说明 |
|------|------|
| 无交易成本 | 未考虑佣金、印花税等（真实环境会侵蚀利润） |
| 无滑点 | 假设所有交易在指定开盘价精确成交 |
| 全额投资 | 每次交易投入全部可用资金 |
| 固定持有期 | 2天固定持有，忽略期间市场变化 |
| 无风险控制 | 未设置止损位 |

## 七、未来优化方向

^future-work

1. **参数优化**：网格搜索或遗传算法为不同股票找最优参数组合
2. **动态卖出策略**：用 KDJ 死叉、RSI 超买等动态退出替代固定持有期
3. **风险管理**：引入止损位（如亏损超 3% 立即平仓）
4. **真实成本模拟**：利用 `backtestEngine` 纳入交易佣金、印花税、滑点
5. **扩展特征集**：引入布林带（Bollinger Bands）、能量潮（OBV）、市场情绪指标等

## 八、各指标分工总结

| 指标 | 角色 | 时间尺度 | 侧重维度 |
|------|------|----------|----------|
| KDJ | 触发器（最敏感） | 短期 | 价格随机位置 |
| RSI | 第一过滤器 | 短中期 | 相对强弱与超买超卖 |
| MACD | 第二过滤器（趋势） | 中长期 | 趋势动能 |
| 换手率 | 确认信号 | 日度 | 市场活跃度和参与度 |

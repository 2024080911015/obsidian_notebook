# 树莓派入门

## 一、树莓派连接WiFi网络

树莓派启动并通过SSH登录后，需要让它连接Wi-Fi。根据系统版本不同，有三种方法。

### 方案 1：raspi-config（推荐，最省事）

在SSH终端中执行：

```bash
sudo raspi-config
```

进入后依次操作：
- 选择 `System Options`（旧版为 `Network Options`）
- 选择 `Wireless LAN`
- 输入你的 Wi-Fi SSID 和密码
- 退出后建议重启：

```bash
sudo reboot
```

### 方案 2：NetworkManager / nmcli（Bookworm 版本）

先确认系统网络管理器：

```bash
lsb_release -a 2>/dev/null
nmcli -v 2>/dev/null
```

如果 `nmcli` 有输出版本号，说明使用 NetworkManager。

**扫描Wi-Fi：**

```bash
sudo nmcli dev wifi rescan
nmcli dev wifi list
```

**连接Wi-Fi：**

```bash
sudo nmcli dev wifi connect "你的SSID" password "你的密码"
```

**检查是否拿到IP：**

```bash
ip a show wlan0
ip r
```

### 方案 3：wpa_supplicant（旧版系统）

编辑配置文件：

```bash
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf
```

在末尾添加：

```
network={
    ssid="你的SSID"
    psk="你的密码"
}
```

保存后执行：

```bash
sudo wpa_cli -i wlan0 reconfigure
sudo systemctl restart dhcpcd
```

检查状态：

```bash
ip a show wlan0
```

### 连接后查Wi-Fi IP

一旦Wi-Fi连接成功，树莓派会拿到新的IP（可能与直连网段不同）：

```bash
hostname -I
# 或只看 wlan0
ip -4 addr show wlan0
```

后续SSH使用Wi-Fi IP：

```bash
ssh <user>@<wlan0的IP>
```

### 快速排查三条命令

如果连不上WiFi，执行以下排查：

```bash
rfkill list
iw dev
sudo journalctl -u NetworkManager -n 50 --no-pager
```

## 二、树莓派与电脑网线直连通信

### 原理

只要电脑和树莓派通过网线处于同一网段、能互相通信，即可SSH，树莓派不需要联网。

### Windows 上开启 Internet 连接共享（ICS）

把电脑的 WLAN（能上网的 Wi-Fi）共享给以太网（直连树莓派的网口）。

^ics-setup

**入口方式 A：**
设置 → 网络和 Internet → 高级网络设置 → 更多网络适配器选项 → WLAN 右键属性 → 共享

**入口方式 B：**
`Win + R` → 输入 `ncpa.cpl` → WLAN 右键属性 → 共享

开启共享后勾选：
- 勾选 "允许其他网络用户通过此计算机的Internet连接来连接"
- 在 "家庭网络连接" 下拉菜单中选择 "以太网"

Windows 共享后通常会把直连口设为 `192.168.137.1`（常见网段）。

### 排查步骤

1. **确认以太网口状态是"已连接"**（不是未连接）

2. **扫描发现树莓派IP**：对 `192.168.137.0/24` 做 ping 探测，再 `arp -a` 找到树莓派IP

3. **兜底方案**：给树莓派 eth0 手动设静态 IP（例如 `192.168.137.2/24`），然后：

```bash
ping 192.168.137.2
ssh pi@192.168.137.2
```

### arp -a 解读

`arp -a` 中可能出现两个接口：

^arp-interpretation

- `192.168.0.100`：电脑在路由器局域网的网段（看到 `192.168.0.1` 正常）
- `192.168.137.1`：共享出来给树莓派的网段

如果在 `192.168.137.1` 下面**没有出现** `192.168.137.xxx` 动态设备，说明树莓派没有拿到该网段IP / 还没被电脑发现 / 链路可能没通。

## 三、无WiFi、无路由器的连接方案

适用场景：老款树莓派无内置Wi-Fi模块（Pi 1, Pi 2, Pi Zero），且没有传统路由器。

### 方法一：电脑共享网络（最推荐）

^share-network

**准备：**
- 一台带Wi-Fi和以太网口的电脑
- 树莓派和电源
- 一根网线
- 智能手机开启个人热点

**操作步骤：**

1. 电脑通过Wi-Fi连接手机热点
2. 网线连接树莓派以太网口和电脑以太网口
3. 在电脑上设置网络共享（参考 [[#^ics-setup|ICS设置]]）
4. 树莓派通电启动

**寻找树莓派IP：**
- `ping raspberrypi.local`（需要系统支持mDNS）
- 使用 IP 扫描工具（如 Advanced IP Scanner）

**远程登录：**

```bash
ssh pi@<树莓派的IP地址>
```

**优点：** 无需额外硬件，连接稳定，树莓派可直接上网。

### 方法二：USB无线网卡

^usb-wifi-dongle

**无头配置（Headless Setup）：**

1. 取下树莓派SD卡，插入电脑
2. 在SD卡根目录（boot分区）创建 `wpa_supplicant.conf`
3. 写入以下内容：

```
country=CN
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1

network={
    ssid="你的手机热点名称"
    psk="你的手机热点密码"
}
```

4. 保存，安全弹出SD卡
5. 将USB无线网卡插入树莓派，插回SD卡
6. 通电启动

树莓派会自动连接配置好的热点。在手机热点管理界面的"已连接设备"列表找到IP。

### 方法三：网线直连（无网络访问）

用网线直接连接树莓派和电脑以太网口。大部分电脑和树莓派支持自动分配链路本地地址（169.254.x.x 网段）。

```bash
ping raspberrypi.local
ssh pi@raspberrypi.local
```

如果 `.local` 地址无效，用IP扫描工具扫描 `169.254.0.0/16` 网段。

**优点：** 最简单的物理连接。**缺点：** 树莓派无法访问互联网。

### 对比总结

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 电脑共享网络 | 稳定可靠，无需额外花费，可上网 | 需要电脑开机作为中介 | 首次配置和日常使用（推荐） |
| USB无线网卡 | 树莓派独立联网，使用灵活 | 需要额外购买硬件 | 希望独立连接Wi-Fi |
| 网线直连 | 连接最简单 | 无法上网，找IP稍麻烦 | 仅需本地登录操作 |

## 四、与MC服务器的联动

树莓派可以作为轻量服务器运行Minecraft服务端，也可以通过SSH远程管理其他机器上的[[../其他项目/Minecraft服务器搭建|Minecraft服务器]]。在连接方式上，树莓派可以使用本节介绍的任何网络方案来加入局域网或互联网。

## 五、补充：Headless Setup 完整流程

对于没有任何显示器、键盘、鼠标的情况，一个完整的Headless Setup流程为：

1. 烧录系统到SD卡
2. 在SD卡boot分区创建空白 `ssh` 文件（启用SSH）
3. 创建 `wpa_supplicant.conf` 配置WiFi（参考 [[#^usb-wifi-dongle|USB无线网卡配置]]）
4. 插入SD卡，树莓派通电
5. 通过路由器管理界面或IP扫描工具找到树莓派IP
6. SSH连接

# 路由器玩法

## 一、路由器基础概念

### 家用路由器结构

家用无线路由器通常将以下功能合并在同一设备中：

^router-structure

- **AP（接入点）**：提供Wi-Fi无线接入
- **交换机**：提供有线LAN端口
- **NAT路由器**：实现内外网地址转换
- **DHCP服务器**：自动分配内网IP

### 双NAT结构

家庭网络中常见"双 NAT"：

^double-nat

```
设备 192.168.0.x
    ↓
家用路由器 LAN：192.168.0.1
    ↓（路由器 WAN 可能是 192.168.1.x）
光猫/上级路由：192.168.1.1
    ↓
运营商：100.64.0.1（CGNAT 迹象）
    ↓
公网互联网
```

双NAT会影响端口映射、外网主动连接和某些P2P场景。

### 常见私有地址范围

| 地址范围 | 用途 |
|---------|------|
| `10.0.0.0/8` | RFC1918 私有 IPv4 地址 |
| `172.16.0.0/12` | RFC1918 私有 IPv4 地址 |
| `192.168.0.0/16` | RFC1918 私有 IPv4 地址 |
| `100.64.0.0/10` | 运营商级NAT（CGNAT）共享地址空间 |

## 二、SSH连接小米路由器

### 前提条件

- 需要路由器已开启SSH功能（部分小米路由器开发版固件支持，或需通过官方渠道解锁）
- 知道路由器的管理IP（通常是 `192.168.31.1` 或 `192.168.0.1`）

### 连接步骤

```bash
# 连接小米路由器（默认用户名通常为 root）
ssh root@192.168.31.1
```

### 常见SSH连接问题排查

1. **连接被拒绝**：确认路由器已开启SSH功能
2. **密码错误**：小米路由器SSH密码通常需要通过官方工具或特定方式获取，不同型号方式不同
3. **网络不可达**：确认电脑与路由器在同一网段

## 三、路由器刷机基础

### 什么是刷机

刷机是将第三方固件（如 OpenWrt、Padavan、DD-WRT）替换原厂固件，以获得更多功能和更高可定制性。

### 常见第三方固件

| 固件 | 特点 | 适用场景 |
|------|------|----------|
| OpenWrt | 开源Linux发行版，包管理完善，插件丰富 | 高级用户，需要丰富插件 |
| Padavan | 基于华硕固件，轻量、稳定、信号好 | 日常使用，注重新号质量 |
| DD-WRT | 老牌第三方固件 | 兼容性好 |

### 刷机基本流程

^flash-router

1. **确认路由器型号和硬件版本**
2. **下载匹配的第三方固件**
3. **进入路由器恢复模式**（通常是断电后按住Reset键再通电）
4. **通过TFTP或Web界面刷入固件**
5. **等待刷机完成并重启**
6. **首次配置**（设置密码、WiFi、网络参数等）

### 注意事项

- 刷机有风险，可能变砖。务必确保固件与设备型号完全匹配。
- 刷机前备份原厂固件配置。
- 确保刷机过程中不断电。
- 某些品牌路由器的Bootloader（如Breed）可以降低变砖风险，先刷入Breed再刷固件更安全。

### 刷机后常用配置

拿到管理员权限后，可以进行以下操作：

```bash
# 更新软件包列表
opkg update

# 安装常用工具
opkg install vim htop curl wget

# 配置防火墙规则
# 配置端口转发
# 配置DDNS
# 配置VPN客户端/服务端
```

## 四、路由器WiFi调优

### 信道选择

- **2.4 GHz**：信道 1、6、11 互不重叠，优先选择
- **5 GHz**：信道多，干扰少。注意 DFS 信道可能因雷达信号自动切换

### 信道宽度

- 20 MHz：最稳定，干扰最小，但速度较慢
- 40 MHz：2.4 GHz 下慎用（容易干扰）
- 80 MHz：5 GHz 下常用，速度与干扰的平衡
- 160 MHz：最高速度，但更容易受干扰

### 信号质量判断

| RSSI（粗略） | 体验 |
|-------------|------|
| 约 -30 ~ -50 dBm | 很强 |
| 约 -50 ~ -67 dBm | 通常很好 |
| 约 -67 ~ -75 dBm | 可用但速率可能下降 |
| 低于 -80 dBm | 较弱，易抖动/掉速 |

## 五、CGNAT与内网穿透

运营商级NAT（CGNAT, 地址段 `100.64.0.0/10`）意味着你没有独立的公网IPv4地址，无法直接从外网访问家中的设备。
